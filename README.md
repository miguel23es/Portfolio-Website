# Personal Portfolio

A personal portfolio website built with **React** to showcase my background, skills, projects, and ways to get in touch with me. The site is designed to be clean, modern, and easy to navigate, serving as a central hub for my work as a software engineer.

---

## 🌐 Live Website  
https://www.miguelespinosa.net

---

## About the Project

I created this portfolio to present myself professionally as a software engineer and to provide an accessible place for recruiters, hiring managers, and collaborators to view my work.

The site includes a clear overview of who I am, my technical skills, and detailed showcases of my key projects, each linking to GitHub repositories and live demos where available.

---

## Features

- **Resume** – Link to my resume 
- **Projects Showcase** – Interactive project cards with links to:
  - GitHub repositories  
  - Live demos / websites  
- **Contact Section** – Ways to reach me (email, LinkedIn, etc.)  
- **Responsive Design** – Optimized for desktop, tablet, and mobile  
- **Modern UI/UX** – Clean, minimal, and professional layout  

---

## Tech Stack

- **Frontend:** React (Vite)  
- **Styling:** CSS  
- **Routing:** React Router  
- **Deployment:** Render 

---

## What I Built

Since this is a personal project, I designed and implemented everything, including:

- Building reusable React components (Project Cards, Navbar, Sections, etc.)  
- Implementing dynamic project data and external links  
- Designing the UI layout and visual theme  
- Ensuring mobile responsiveness  
- Deploying the site and connecting a custom domain
